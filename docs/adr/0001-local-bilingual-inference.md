# Keep the bilingual assistance pipeline local

QVAC Sovereign Agent will run transcription, TranslatePsy translation, RAG and Supported Guidance generation in the local QVAC environment. This choice makes the Bilingual Bridge central to the QVAC Psy submission and keeps call content and Knowledge Documents away from external AI providers, accepting tighter hardware limits and the need to measure local latency and translation quality.
