# Reproducir la evaluación y preparar la entrega del hackathon

## Objetivo

Ejecutar 20 casos, exportar el registro de rendimiento requerido y documentar una demo de cinco minutos reproducible.

## Valor visible

Entrega evidencia medible de calidad, rendimiento, privacidad y utilidad empresarial para los jueces.

## Alcance

- Completar 20 casos bilingües con referencia revisable.
- Medir Precision@1, Recall@3, entidades, citas, abstención y latencias.
- Exportar carga de modelo, prompts/entradas, tokens, TTFT y throughput cuando aplique.
- Añadir instrucciones exactas de instalación, modelos, hardware y ejecución.
- Preparar guion y checklist del video.

## Criterios de aceptación

- Precision@1 alcanza al menos 85 % o el informe explica el resultado real.
- El 100 % de entidades se conserva o bloquea.
- La conversación demo funciona sin APIs externas de IA.
- Otra persona puede reproducir instalación, indexación, evaluación y demo.
- El repositorio identifica todos los modelos, cuantizaciones y terceros con honestidad.

## Dependencia

Bloqueado por #7, audio y Zero-Retention Mode.
